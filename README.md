# leoq77777.github.io

Personal page of Yutong Qin. Plain HTML + CSS, no build step.

- `index.html` — content
- `style.css` — styling (palette after *The Age of Innocence*)
- `assets/bg.jpg` — Henri Fantin-Latour, *Still Life with Roses and Fruit* (1863), The Met, public domain
- `deploy.sh` — one-time setup: downloads the background, creates the GitHub repo, pushes

After the first deploy, update with `git add -A && git commit -m "..." && git push`.
