I. About

I build systems where performance is something you can measure — recommendation serving at production scale, low-latency C++ for markets, and inference engines for large language models.

I studied economics at Nanjing University before moving into computer science, and I am now a graduate student at Columbia. Between the two I spent an internship on Kuaishou’s recommendation engine team in Beijing. These days I am most interested in quantitative development, ML systems, and the place where the two meet.

III. Selected Work

FastLOB

C++20

A market-by-order limit order book engine built around fixed-size memory pools, intrusive FIFO queues and open-addressing indexes. Add/cancel paths went from 47.5 ns to 9.8 ns per operation on Apple M5, with zero mismatches across 50,000 replayed events.

nano-vLLM-MLX

Python · MLX

An LLM inference engine for Apple Silicon with continuous batching, paged attention, chunked prefill, prefix caching and preemption. Benchmarked on Qwen3-0.6B for time-to-first-token and throughput under concurrent load.

MiniRay

C++

A small distributed task runtime inspired by Ray: task scheduling, RPC, resource management, heartbeats, retries and failure recovery.

Tiny Web Server

C++

An event-driven HTTP/1.1 server on the Reactor pattern with epoll, non-blocking sockets, a thread pool and asynchronous logging. About 72.6K requests/sec with 10,500 concurrent clients and zero failures.

ZQR

Python

An agent-based quantitative research platform, which I use to explore how language-model agents can search for and test trading ideas.
