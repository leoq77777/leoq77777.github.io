About

I build systems where performance is something you can measure — recommendation serving at production scale, low-latency C++ for markets, and inference engines for large language models.

I studied economics at Nanjing University before moving into computer science, and I am now pursuing an M.S. at Columbia. In between, I spent an internship on Kuaishou’s recommendation engine team in Beijing. These days I am most interested in quantitative development, ML systems, and the place where the two meet.

II

Selected Work

01

C++20 · Market data

FastLOB

A market-by-order limit order book engine built around fixed-size memory pools, intrusive FIFO queues and open-addressing indexes, with optimized add and cancel paths. Zero mismatches across 50,000 replayed events, and clean under sanitizers.

47.5 ns ↓ 9.8 ns per operation · Apple M5
02

Python · MLX

nano-vLLM-MLX

An LLM inference engine for Apple Silicon: continuous batching, paged attention, chunked prefill, prefix caching and preemption, benchmarked on Qwen3-0.6B.

03

C++ · Distributed

MiniRay

A small distributed task runtime inspired by Ray: scheduling, RPC, resource management, heartbeats, retries and failure recovery.

04

C++ · Networking

Tiny Web Server

An event-driven HTTP/1.1 server on the Reactor pattern with epoll, non-blocking sockets, a thread pool and asynchronous logging; 10,500 concurrent clients, zero failures.

05

Python · Agents

ZQR

An agent-based quantitative research platform for exploring how language-model agents can search for and test trading ideas.
